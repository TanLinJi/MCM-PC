项目概览

一句话目标

做 3D 点云的测试时适配 (Test-Time Adaptation, TTA) 方法，让 OpenShape 类零样本分类器在面对分布偏移时保持鲁棒；实验上用可控 benchmark corruptions (scale / rotate / noise) 作为代理和压力测试，且不重训。投稿 AAAI 2027。

  2. 单点文本锚点 — 表达不了类内多样性，文本先验拟合不足。

三贡献 Deep-Dive

C1 · ICP-CD 几何距离

痛点：特征余弦在部分 benchmark 全局几何 corruption (scale / rotate) 上可能失效。

方法：PCA 主轴 + ICP (Iterative Closest Point) 精调 + Chamfer Distance 比较形状。CD 对 scale 归一化点云天然不变。

实现位置：model_with_mcp3d.py Section 4 (L~150-250)

风险闸 R3 (W4)：ModelNet-C scale_2 severity 上单 ICP-CD 必须 ≥ ZS baseline，否则 C1 的 benchmark motivation 倒塌。

写作：§3.4 在 W4 完成

C2 · vMF 文本锚点

痛点：单 template 表达不了类内多样性。

方法：用 DeepSeek API 生成每类 30 个 paraphrase → CLIP 编码 → 用 von Mises-Fisher 分布 (球面高斯) 拟合球面分布 → Maximum a Posteriori (MAP) 估计锚点中心 μ 和集中度 κ。

为什么不在点云侧用 vMF？样本量对称性 / 算力成本 / 维度差异（详见 Q4）。

实现位置：model_with_mcp3d.py Section 3 (L~60-149) + generate_paraphrase.py

风险闸 R2 (W3)：vMF 精度 vs 简单平均 ≥ 0.1pp，否则 vMF 降附录。

写作：§3.3 在 W3 完成

C3 · 2×3 记忆矩阵

架构载体：3 列 (ZS anchor / point-cloud cache / boundary memory) × 2 行 (high-conf / low-conf)，6 格各独立贡献一条证据，通过 z-score 跨格融合。

关键澄清：低置信度样本 不是负样本，是 boundary memory（模糊样本），存 top-k 软标签，作用是校准信号 (Q3 详述)。

实现位置：model_with_mcp3d.py Section 6-7

写作：§3.5 在 W5 完成，含 leave-one-out 6-cell 消融（修补 G3）

Q3 — 2×3 矩阵第二行（低置信度样本）是负样本吗，能不能用损失函数排斥？

A3：不是负样本，是 boundary memory（模糊样本）。

不是负样本

  • 负样本机制：用损失函数（如 InfoNCE）让特征远离它
  • 但 MCP-3D 是 TTA 范式 = 免训练 (training-free) — 没有损失函数

是模糊样本 (boundary memory)

  1. 收集：top-1 置信度低 (例如 < 0.3) 的样本放进 boundary memory
  2. 存的不只是特征：还存 top-k 类别软标签 e.g. [chair: 0.4, sofa: 0.35, stool: 0.25]
  3. 用法：新样本和某 boundary 余弦高 → 说明新样本也在"模糊区" → 用 boundary 软标签和主预测加权融合 → 降低主预测置信
  4. 本质：校准信号，告诉 fusion"这个区域不要瞎自信"

修补漏洞：G6 (W: docs 没说清 boundary memory) — 复习期间立即可改

Q4 — 为什么 vMF 用在文本不用在点云特征？

技术上两边都能用 vMF，但只在文本侧用是设计权衡。三个理由：

文本侧点云侧
样本量每类 ~30 paraphrase，需要参数化分布拟合才稳cache 里 ~100-500 同类样本，经验分布够用
算力每类算一次 MAP，可提前算好每 batch 更新 cache，每批 N 个类重拟合 vMF 太贵
维度CLIP d=512，中维球面 vMF 拟合稳定OpenShape d=1280，vMF 优势衰减

修补漏洞：G7 (W: docs 没解释为何不对称使用) — 复习期间立即可改，§3.3 末段加 short paragraph
