## 1. 我们在解决什么问题：3D 点云的 Test-Time Adaptation (TTA)

**TTA** 是这样一类问题：

- **训练时**：模型在干净数据上训练
  - 比如 ModelNet 这种 3D CAD 模型，没有噪声
- **部署时**：实际输入有各种破坏
  - 传感器噪声（jitter）
  - 物体被遮挡（dropout，缺失部分点）
  - 旋转方向不对（rotate）
  - 比例失真（scale）
- **目标**：模型在测试时**边推理边适应**
  - 不修改参数（不能反向传播）
  - 不需要标签（无监督）

---

## 2. 为什么 3D 比 2D 更难

3D 点云有一个 2D 图像没有的额外维度——**几何结构**。

举个例子：一把椅子被旋转 30°：

```
2D 图像角度：    像素位置变了，但内容还是一张图
3D 点云角度：    每个点的 (x, y, z) 坐标全变了
                 feature encoder 可能就不认识了
```

这就是 3D TTA 难的原因：现有方法处理"旋转、抖动、缺失"这类**几何破坏**时，feature 距离会失灵。

---

## 3. 现有 SOTA：Point-Cache（CVPR'25）

Point-Cache 的思路很简单：

```
1. 测试时遇到一个新点云 X，用 3D-VLM 编码成 feature z
2. 把 z 与"记忆库"里每类的 K 个 anchor feature 比较
3. 距离越近，越可能是该类
4. 用 z 的预测结果回去更新记忆库（保留高置信样本）
```

它用了两层记忆库（global + local），效果在 ModelNet-C 上不错。

---

## 4. Point-Cache 的 3 个软肋（MCP-3D 要解决的）

### 软肋 1：文本锚点不够准
- 它用 64 个固定模板的算术平均作为类锚点
- **问题**：算术平均忽略"特征住在球面上"这个事实
- **MCP-3D 解法**：用 vMF 分布的 MAP 估计（球面上的"加权平均"）

### 软肋 2：只靠 feature 距离，遇到几何破坏会崩
- 编码器号称"近似旋转不变"，但实际上不完美
- 旋转 90° 后，同类样本可能被推到 cosine 相似度 0.5 以下
- **MCP-3D 解法**：用 ICP（Iterative Closest Point）+ Chamfer Distance 直接比较 3D 形状

### 软肋 3：不知道记忆库是不是在"散开"
- 记忆库随测试推进会逐渐变质
- 2D 的 MCP 论文（ICCV'25）发现：紧致性下降 → 精度下降，相关系数 r ≈ 0.82
- **MCP-3D 解法**：在 3D 上做同样的诊断，验证这个现象是否普适

## 5. MCP-3D 的 3 个 Contributions

| 编号 | 内容 | 类型 | 风险等级 |
|------|------|------|----------|
| **C1** | ICP-CD 几何距离 | 新方法 | 🔴 高（feature 失败假设需验证） |
| **C2** | 紧致性诊断 | 科学发现 | 🟡 中（标签泄露风险） |
| **C3** | 2×3 记忆矩阵 | 工程整合 | 🟡 中（leave-one-out 必做） |
| **C4** | vMF 文本锚点 | 数学严谨化 | 🟢 低（确定有数学根据） |

## 6. 整合架构：2×3 记忆矩阵

把 6 个记忆格子组织成两个轴：

```
                  | global         | local
                  | (整个点云)     | (5 个 patch)
       -----------+----------------+----------------
       confidence | global_conf    | local_conf
       (置信)     | (低 entropy)   | (低 entropy patch)
       -----------+----------------+----------------
       compactness| global_comp    | local_comp     <-- 这里用 ICP-CD
       (紧凑)     | (CD 小)        | (patch CD 小)
       -----------+----------------+----------------
       boundary   | global_bnd     | local_bnd
       (边界)     | (中 entropy)   | (中 entropy patch)
```

每个格子存 K=3 个 anchor 样本，每类共 18 个 anchor。

最终预测公式（口述版）：
```
final_logits = text_logits 
             + 5 个正向格子的加权和 
             - 1 个 boundary 格子的加权（负号，捕捉模糊样本）
```

## 7. 项目的故事一句话

> *3D 点云 TTA 有 3 个特殊挑战，对应 3 个贡献。我们提出几何感知的多记忆框架，
