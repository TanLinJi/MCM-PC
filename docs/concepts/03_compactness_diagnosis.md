## 2. 背景：MCP 论文（2D 图像）的发现

MCP 是 ICCV'25 的论文（"Memory Compactness Pivot"），它在 **2D 图像 TTA** 上发现了一个有趣现象：

> **记忆库的"紧致性" Phi(c) 随时间下降，与最终精度强正相关**
> **Pearson 相关系数 r ≈ 0.82**

### 2.1 紧致性的定义

```
对于类 c 的记忆库（包含 K 个 anchor 样本 z_1, ..., z_K）：

Phi(c) = mean over k [ ||z_k - a_c|| ]

其中 a_c 是该类的文本锚点

含义：
  Phi 小 -> K 个 anchor 都靠近锚点 -> "紧致" -> 类内方差小 -> 决策稳
  Phi 大 -> K 个 anchor 散得很开 -> "松散" -> 类内方差大 -> 决策不稳
```

### 2.2 MCP 在 2D 上的发现

```
随着 TTA 推进（每个测试样本进来）:
  时刻 t=0：所有类的 Phi 较小（记忆库刚建好）
  时刻 t=1000：某些类的 Phi 上升（被噪声污染）
  时刻 t=5000：Phi 高的类，精度也低（强相关）

最终：r(Phi, accuracy) ≈ 0.82
```

## 3. 我们要做的事：在 3D 上验证这个现象

### 3.1 为什么这有意义

**情况 A：3D 也有 r ≈ 0.82**
```
意义：这个现象是"跨模态普遍"的
论文 contribution："发现了一个普适规律"
影响：3D TTA 设计应该参考这个观察
```

**情况 B：3D 是 r ≈ 0.65（弱一些）**
```
意义：3D 有 corruption-specific 的特性
论文 contribution："3D 有不同的失败模式"
影响：紧致性只对部分损坏类型有效
```

**情况 C：3D 是 r ≈ 0.05（无关）**
```
意义：2D 的发现在 3D 不成立
论文 contribution 失败 -> 改写"为什么 3D 不一样"的反向叙事
影响：整个 C2 要重新规划
```

## 4. 怎么测紧致性

### 4.1 数据流程

```
步骤 1：跑一次完整 TTA
  对测试集每个样本 X_i:
    1. 用 3D-VLM 编码 -> z_i
    2. 用 Point-Cache 预测 -> y_i_hat
    3. 更新记忆库（保留 K 个最佳样本/类）
    4. 在第 i 步结束后：
       - 记录每类 c 的当前 Phi(c)：mean ||z_k - a_c||
       - 记录当前 100 步窗口内的精度

步骤 2：收集数据点
  最终得到一个数据集：
    每个数据点 = (Phi 值, 该时刻的精度)

步骤 3：计算 Pearson r
  r = correlation(Phi 序列, 精度序列)
```

### 4.2 多种粒度的紧致性

```
紧致性可以在不同粒度测：

a) 类级 Phi(c)：每类单独的紧致性
b) 全局 Phi：所有类的平均紧致性
c) 损坏类型级 Phi：每种损坏类型下的紧致性

实验时全部测，画 4 种 r 值的对比表
```

## 5. 这个 contribution 最大的"反对意见"（Gap B2）

### 5.1 问题：测紧致性需要标签！

```
紧致性 Phi(c) 的定义：
  Phi(c) = mean over k [ ||z_k - a_c|| ]
  
其中 z_k 是"类 c 的"K 个 anchor

但我们怎么知道 z_k 真的属于类 c？
  -> 需要真实标签！
  -> 但 TTA 是无监督的，没有真实标签！
```

### 5.2 我们的回应（写在 N+3 章节）

**核心论证**：

```
这是【离线诊断】，不是【在线方法】

离线诊断的意思：
  1. 先做完一次 TTA（不需要标签）
  2. 然后我们【作为研究者】用真实标签测紧致性
  3. 目的是【理解】TTA 的成败原理

在线方法的意思：
  1. TTA 推理过程中实时使用紧致性
  2. 用紧致性来动态调整记忆库
  3. 这个我们【没有】做（也不能做，因为没标签）

所以：
  - 紧致性是一个【理解工具】，不是【性能工具】
  - 实际部署时不需要它
  - 但它告诉我们 TTA 为什么 work / 为什么 fail
```

### 5.3 这个论证够强吗

```
够强。审稿人可能问：
  "测了又不能用，意义在哪？"
  
我们的回答：
  科学发现的意义不在于工程价值，在于知识价值。
  这个测量帮我们：
    1. 选择 anchor sample 的策略（间接指导 design）
    2. 解释为什么某些损坏类型 TTA 难（fail mode 分析）
    3. 为后续工作提供 baseline 数字
```

但要写得**很清楚**，避免审稿人误解为"假装有方法但其实没用"。

## 6. 用一个比喻

```
你给孩子拍了 100 张照片放进相册（这是记忆库）

紧致性 = 这些照片放在一起像不像同一个人

  紧致性高（Phi 小）：都是 5 岁的他，认得出
  紧致性低（Phi 大）：5 岁的、10 岁的、戴口罩的、戴墨镜的，混在一起，认不出

紧致性诊断 = 在事后，比较"相册的紧致性"和"未来识别准确率"
              发现两者相关
              -> 知道了"相册松散" = "认人不准"

这是一个【发现】，不是一个【工具】
但这个发现告诉我们：在制作相册时，应该想办法保持紧致
```
