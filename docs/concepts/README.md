## 阅读建议

1. **第一遍**：连续读完所有 5 份文件，不深究公式细节，只抓"为什么这么做"
2. **第二遍**（如有疑问）：针对不懂的概念回到对应文件，看比喻和具体例子
3. **第三遍**（动手前）：读 `04_2x3_memory_matrix.md` 的"6 格子分工"部分，确保你能口述

读完后，你应该能向别人解释：
- MCP-3D 在解决什么问题
- 为什么 Point-Cache 不够用
- 3 个贡献分别针对哪个软肋
- 6 个记忆格子的分工
- 哪些是高风险的（W2.5 探针实验的 gate）
