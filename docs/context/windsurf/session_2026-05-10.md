### 三种 cache 的 runner
- `--cache-type global` → `runners/model_with_global_cache.py`
- `--cache-type local` → `runners/model_with_hierarchical_caches.py`（只用 patch）
- `--cache-type hierarchical` → `runners/model_with_hierarchical_caches.py`（global + patch，**论文主方法**）

### 数据流关键位置
```
utils/utils.py:340-377                 get_openshape_logits（CLIP logit 计算）
models/openshape/ppta.py:99-109        cluster_patches（KMeans 5 patches）
runners/model_with_hierarchical_caches.py:
    17-67                              build_cache_in_advance（预扫 test set 填 cache）
    70-108                             update_cache（entropy 淘汰机制）
    110-143                            compute_cache_logits（Tip-Adapter 核，global）
    146-173                            compute_local_cache_logits（5 patch 均值 query）
    177-232                            run_test_tda（主循环：update + 三路 logits 融合）
```

### 关键公式
```
# Zero-shot（utils.py:352）
clip_logits = 100. * pc_feats @ clip_weights

# Cache logits（Tip-Adapter 核，model_with_global_cache.py:122）
cache_logits = ((-1) * (beta - beta * affinity)).exp() @ cache_values
             = exp(-β(1 - A)) · V
             = exp(β·A - β) · V     （A = cosine similarity，已 L2-normalized）

# Final 三路融合（run_test_tda 主循环）
final = clip_logits + α_pos·pos_cache_logits + α_pos·local_cache_logits - α_neg·neg_cache_logits
```

### 超参（configs/modelnet_c.yaml）
```yaml
positive: { shot_capacity: 3, alpha: 2.0,   beta: 3.0  }
negative: { shot_capacity: 2, alpha: 0.117, beta: 1.0,
            entropy_threshold: [0.2, 0.5],
            mask_threshold:    [0.03, 1.0] }
```

## 下一步：双 T4 并行脚本模板（未创建，待用户决定执行）

位置：`Point-Cache/scripts/run_tta_modelnet_c_l2_dual_t4.sh`

```bash
#!/bin/bash
set -e
cd "$(dirname "$0")/.."

CKPT=weights/openshape/openshape-pointbert-vitg14-rgb/model.pt
LOG_DIR=logs/tta_modelnet_c_l2_$(date +%Y%m%d_%H%M%S)
mkdir -p "$LOG_DIR"

CORRUPTIONS=(jitter_2 scale_2 rotate_2 dropout_global_2 dropout_local_2 add_global_2 add_local_2)

run_one () {
    local gpu=$1
    local cor=$2
    echo "[GPU $gpu] launching $cor ..."
    WANDB_MODE=offline CUDA_VISIBLE_DEVICES=$gpu \
    python runners/model_with_hierarchical_caches.py \
        --config configs \
        --lm3d openshape \
        --cache-type hierarchical \
        --ckpt_path "$CKPT" \
        --dataset modelnet_c \
        --cor_type "$cor" \
        --npoints 1024 \
        --oshape-version vitg14 \
        --wandb-log \
        > "$LOG_DIR/${cor}.log" 2>&1
    echo "[GPU $gpu] $cor done -> $LOG_DIR/${cor}.log"
}

i=0
for cor in "${CORRUPTIONS[@]}"; do
    gpu=$(( i % 2 ))
    run_one "$gpu" "$cor" &
    pids[$i]=$!
    i=$(( i + 1 ))
    if [ $(( i % 2 )) -eq 0 ]; then
        wait "${pids[$((i-1))]}" "${pids[$((i-2))]}"
    fi
done
wait

echo "All 7 settings done. Logs at: $LOG_DIR"
grep "Final" "$LOG_DIR"/*.log
```

预计运行时间：~3.5 个串行实验时间（双卡并行 4+3）。
