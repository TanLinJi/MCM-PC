1. 文件组织

ModelNet-C 是 ModelNet40 测试集的 corruption 版本。每一个损坏类型和强度对应一个独立的 .h5 文件。

文件名部分含义例子

3. HDF5 字段

HDF5 是一种常见的二进制数据文件格式，后缀通常是 .h5。本项目读取 ModelNet-C 时只使用两个字段：data 和 label。

字段shape / dtype含义代码读取位置
data(2468, 1024, 3)
通常 float32，部分 jitter 文件是 float64		点云坐标。2468 个测试样本，每个样本 1024 个点，每个点有 x/y/z 三个坐标。Point-Cache/datasets/modelnet_c.py
label(2468, 1)
int64		类别编号，范围 0 到 39。编号映射到 shape_names.txt 中的 40 个类别名。Point-Cache/datasets/modelnet_c.py

6. 最重要的规则：index 对齐

不同 corruption 文件按相同 index 对齐。也就是说，同一个 index 对应同一个物体的不同版本。

clean[17]
第 17 个物体的干净点云
→
scale_2[17]
同一个物体的 scale_2 版本
→
jitter_3[17]
同一个物体的 jitter_3 版本

这就是 P1 可以比较 clean[i] 和 scale_2[i] 的原因。它们不是随机两个样本，而是同一个测试物体的不同损坏版本。

抽查确认：scale_2、jitter_3、rotate_4、dropout_global_4 的 label 都与 clean 完全一致。

7. 加载代码做了什么

f = h5py.File(f'{self.dataset_dir}/{cor_type}.h5')
self.test_data = f['data'][:]
self.test_label = f['label'][:]

pc = self.test_data[idx].astype(np.float32)
if self.lm3d == 'openshape':
    pc[:, [1, 2]] = pc[:, [2, 1]]

label = self.test_label[idx].astype(np.int32)
classname = self.classnames[int(label)]
rgb = np.ones_like(pc) * 0.4

OpenShape 分支会交换 y/z 轴，并给每个点补一个常数 RGB 通道 0.4。原始 HDF5 只有 xyz，没有 RGB。

8. 它怎样支持 anchor pollution 验证

设置queryanchor pool回答的问题
A: corrupt-as-anchorf_corr[i]{f_corr[j]}像 Point-Cache 测试流 cache 一样，用损坏样本当 anchor，会有多准？
B: clean-as-anchorf_corr[i]{f_clean[j]}如果 anchor pool 不被 corruption/test-stream 污染，会有多准？

因为 query 一直是 f_corr[i]，唯一改变的是 anchor pool，所以 B - A 可以解释为 anchor source 的影响。

9. 和当前论文主线的关系

如果 clean[i] 与 corrupted[i] 的 feature 仍很像，
但 clean anchor pool 明显优于 corrupted anchor pool，
那么问题更像是 anchor pollution，而不是 feature failure。

这正是 scale 上观察到的结果。因此我们现在把 C1 从 raw ICP-CD 改成 conditional anchor switching。
